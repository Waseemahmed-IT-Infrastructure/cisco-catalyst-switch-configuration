
# Cisco Catalyst Switch Configuration

## Overview

This project documents Cisco Catalyst switch configuration and network management tasks.

I have worked with Cisco switches during enterprise network deployments, including an eight-switch deployment at one site.

The main tasks included VLAN configuration, IP addressing, access and trunk ports, switch security and network monitoring.

## Configuration Areas

- VLAN creation and port assignment
- Access and trunk port configuration
- Switch management IP and default gateway
- Rapid PVST and loop prevention
- Port security and broadcast storm control
- DHCP snooping on trusted uplinks
- SNMP monitoring and access control
- Basic switch troubleshooting

## Switch Model

Cisco Catalyst 2960-X

## Useful Verification Commands

| Command | Purpose |
|---|---|
| `show running-config` | View the current configuration |
| `show vlan brief` | Check VLANs and assigned ports |
| `show interfaces status` | Check port status |
| `show interfaces trunk` | Check trunk connections |
| `show spanning-tree` | Check spanning-tree status |
| `show ip interface brief` | Check interface IP addresses |
| `show logging` | Review switch logs |

## Monitoring

Switch monitoring can help identify connectivity problems, interface status changes and other network issues.

My work also includes SNMP monitoring and checking wireless access points through Cisco Catalyst Center.
